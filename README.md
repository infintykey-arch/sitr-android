# سِتر 1.6.1 — تنظيم مشاريع وخزنة محلية

«سِتر» ينظم المشاريع وإصداراتها وملفاتها على الجهاز، مع خزنة أسرار مستقلة لكل مشروع وخزنة عامة اختيارية. لا يستخدم التطبيق خادمًا أو مزامنة سحابية.

تستخدم واجهات الدخول والقفل والشاشة الرئيسية، وكذلك أيقونة Android، صورة شعار سِتر التي زوّد بها المالك.

## المشاريع والملفات

لكل مشروع إصدارات منفصلة، ولكل إصدار قائمته الخاصة من الملفات؛ تبقى خزنة المشروع واحدة ومشتركة بين جميع إصداراته. عند إضافة ملف، يحتفظ سِتر بنسخة مشفرة في مساحة التطبيق الخاصة، بينما يبقى الملف الأصلي في موقعه على الهاتف كما هو. حذف نسخة من سِتر لا يحذف الأصل.

اضغط مطولًا على ملف لبدء التحديد المتعدد. يمكن حذف الملفات المحددة من الإصدار، أو تصديرها في ZIP، أو نسخها إلى سجل في خزنة المشروع؛ الإضافة إلى الخزنة تنشئ نسخًا معاد تشفيرها ولا تزيل ملفات الإصدار. يدعم التطبيق فحص واستخراج ZIP، وطلب تثبيت APK عبر مثبت Android، وفتح PDF وWord بالتطبيقات المثبتة، وتحرير ملفات النص والكود حتى 1 ميغابايت.

## الخزنات والأمان

تُشفّر ملفات المشاريع محليًا بـ AES-GCM، كما تُشفّر أسماء المشاريع وفهارس الإصدارات ومحتويات الخزنات محليًا. مفتاح مساحة العمل محمي في Android Keystore ويفتح ببصمة الإصبع. كلمات مرور الخزنات مستقلة، بحد أدنى 8 أحرف، وتُطبّق مهلة متزايدة بعد المحاولات الخاطئة.

**نسيت كلمة المرور؟** البصمة تفتح مساحة العمل ولا تستعيد أسرار الخزنة المشفرة بكلمة مرورها القديمة. خيار «نسيت كلمة المرور؟» يعرض تحذيرًا ثم يتطلب تحققًا جديدًا بالبصمة وكلمة مرور جديدة مؤكدة لا تقل عن 8 أحرف. عند إتمام الخطوات داخل التطبيق، تُعاد تهيئة الخزنة المحددة فقط ويُحذف محتواها السابق (السجلات والأسرار والملاحظات ومرفقاتها) نهائيًا؛ لا تُستعاد الأسرار القديمة. ملفات المشاريع والخزنات الأخرى لا تتأثر. إلغاء التحذير أو فشل البصمة أو عدم حفظ كلمة المرور الجديدة لا يغيّر الخزنة.

## البناء والاختبارات

يتطلب البناء Android SDK وJava. شغّل اختبارات الوحدة وLint باستخدام:

```sh
./gradlew testDebugUnitTest lintDebug
```

لإنشاء Release موقّع، عيّن متغيرات البيئة `SITR_RELEASE_KEYSTORE` و`SITR_RELEASE_STORE_PASSWORD` و`SITR_RELEASE_KEY_ALIAS` و`SITR_RELEASE_KEY_PASSWORD` إلى إعدادات مفتاح سِتر المحفوظة لديك، ثم شغّل:

```sh
./gradlew assembleRelease
```

لا يتضمن أرشيف المصدر ملف المفتاح أو كلمات مروره أو إعداد `local.properties`. حُفظت هوية توقيع Release نفسها المستخدمة في إصدار سِتر 1.5.0.
